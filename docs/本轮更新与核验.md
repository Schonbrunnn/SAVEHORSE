# 本轮更新与核验 · 2026-09-11

## 已接入

- 保留 Phaser、Vite 与 GitHub Pages 工作流，不更换游戏架构。
- A/B/C/D 战斗状态使用各自的独立透明 PNG；选人与对话使用独立 portrait。A 的部分状态复用稳定姿态，D 固定机甲采用同一基底叠加程序特效，具体边界见《角色资源规范》。
- C 补齐刀战、追击跳跃、持枪、开火与受击；残血切枪后不再在移动时拿回刀。
- D 的实际机甲轮廓待机占 720 逻辑高度的 57.3%、受击为 55.0%，独立的预警与特效不会跨动作格裁切。最终竞技场为 1280 宽固定镜头，保留地面与两层平台。
- 三类小兵、七种技能特效拆成独立透明图；弹丸素材居中对齐伤害点。
- 修正动态物理代理重复缩放、小兵入场透明度被动作切换打断、飞行怪/Boss 重力 API、重启后的旧 Boss 血条引用等问题。
- 暂停、对话与商店冻结攻击预警及动画，恢复时补偿战斗时间；手机短触控不会因发生在两帧之间而丢失。

## 验证范围

- `pnpm game:build`、ESLint 与差异空白检查；`node scripts/verify-character-assets.mjs` 验证 48 张独立 PNG 的真实透明与安全留白，以及 5 张纯净 portrait 的尺寸和 Alpha。
- 浏览器实际观察 A/B 完整人物、C 入场与阶段切换、D 完整机甲与弹幕预警。
- Map1 依次生成 2、3 名小兵；前批死亡后才出后批；清场后道路解锁，最终留下 5 堆无碰撞白骨。
- 二段跳达到第二跳状态；手机横屏尺寸下显示左侧三键、右侧三键。
- 暂停逻辑使用项目安装的 Phaser Clock 做嵌套暂停、弹丸寿命、首次受击到阶段对话的时序测试。

本轮测试不是 iPhone 真机 Safari 验收；Safe Area、音频解锁、多点触控与真机性能仍需实际设备复核。没有推送 GitHub 或发布外网新版本。

素材生成方式、实际提示词、算法透明处理与资源目录分别见《Boss生成记录》《人物生成素材清单》《角色资源规范》。
