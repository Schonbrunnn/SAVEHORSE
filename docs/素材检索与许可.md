# 素材检索与许可记录

检索日期：2026-09-10

## 调研结论

现成免费素材中，CraftPix 的角色动作最完整，Kenney 和 OpenGameArt 的 CC0 素材许可最清晰；但它们分别偏矢量卡通或像素风，与项目现有的高清写实漫画人物差异明显。为了避免风格割裂及把第三方源 PNG 随 GitHub 仓库重新分发的许可问题，本版仅将这些资源用于动作拆分、视差层与碰撞块设计参考，实际小兵、特效和场景使用项目专属原创素材。
