# 《宝马之路》初版游戏设计说明

历史范围：本文保留初版玩法与美术方案，其中第 5 节的 Canvas 原图裁切、尺寸和“不重绘”描述属于早期方案。当前工程使用构建后的独立动作 PNG、portrait、算法 Alpha 和 Tween；实际资源规范与限制见 `docs/角色资源规范.md`。

## 1. 一句话定位

一款单人 PVE、三关卡、横屏网页格斗游戏：第一关采用《合金弹头》式横向推进，后两关进入锁定竞技场，以近距离格斗和易读前摇为核心。

## 2. 主线剧情

小马国公主被带往国轩之窟。奇瑞队长与上海交通骑士收到救援消息，玩家选择其中一位出发：

1. 穿越洞窟前线，清理拦路伏兵。
2. 在封闭竞技场击败守门人秦岭杀人兔·玥。
3. 经过神秘商人泉的夜市，选择一件免费补给。
4. 深入国轩之窟，击败草莓熊博士·珏并救出公主。

## 3. 关卡节奏

### 第一关：洞窟前线

- 地图长度 3400 逻辑像素，镜头跟随玩家向右推进。
- 八名小兵分段出现，接近后有 0.38 秒攻击前摇。
- 最后一个路口未清敌时会封锁推进；清敌后抵达洞口过关。
- 目标是让玩家学会移动、攻击、技能和闪避，不设置 Boss。

### 第二关：秦岭杀人兔·玥

- 进入后锁定 1280×720 竞技场。
- HP 100%～20%：追击、挥刀、突进斩；高威胁动作前摇不少于 0.34 秒。
- HP ≤ 20%：自动切枪，改用固定方向单发或三连发，子弹不会持续追踪。
- 战胜后必定触发神秘商人。

### 神秘商人：泉

三选一且不收费：

- 回血药水：立即回满。
- 上限提升果：最大 HP +25，同时回满。
- 锋利刀：攻击力 +20%，并回复少量生命。

### 第三关：草莓熊博士·珏

- Boss 本体固定在右侧，玩家可在左侧至 Boss 前方活动。
- Phase 1：召唤小熊、三线弹幕、熊掌炮。
- HP ≤ 50%：进入 Overdrive，加入五发扇形弹幕并缩短间隔。
- HP ≤ 20%：触发一次最终激光；显示 1.2 秒危险带，玩家通过跳跃躲避。
- 敌方弹幕在任何时刻最多 10 枚，小熊最多 3 只。

## 4. 可选角色

### A 奇瑞队长

- 120 HP，移动速度 235。
- 盾击二连：10 / 12 伤害。
- 回旋飞盾：自动按面朝方向发射，出程与回程可分别命中。
- 技能冷却 3.8 秒，适合第一次游玩。

### B 上海交通骑士

- 100 HP，移动速度 285。
- 人与电瓶车始终作为一个整体。
- 前轮二连：9 / 11 伤害。
- 直线冲锋：22 伤害，自动按面朝方向冲刺。
- 技能冷却 4.2 秒，机动性更高。

## 5. 美术与脸部一致性

- 玩家、Boss、商人均直接复用 `人物美术设计` 的原始高清 PNG。
- 战斗中通过 Canvas `drawImage` 的源区域裁切调用原图，不对脸部做 AI 重绘。
- 玩家约占画面高度 42%，玥约占 58%，珏的机甲约占 62%，强调高清大人物而非像素小人。
- 动作感来自整体位移、倾斜、刀光、速度线、受击闪烁和镜头震动；初版不伪造额外脸部帧。
- 后续如制作逐帧动画，必须以现有正脸/侧脸为身份参考，并建立角色脸部锚点表后再扩图。

## 6. 移动端约束

- 固定 1280×720 逻辑分辨率，按 16:9 等比缩放。
- 竖屏触摸设备显示旋转提示，不依赖网页强制旋转。
- 页面禁用缩放、滚动、回弹与系统长按菜单。
- 使用 `viewport-fit=cover` 和 Safe Area 环境变量避开刘海 / Dynamic Island。
- 每个触控按钮独立监听 Pointer 事件，可同时按住方向和攻击。
- 首次点击“踏上救援之路”时解锁 Safari Web Audio。

## 7. 当前初版边界

- 使用高清立绘的整体变换模拟战斗动作，未制作完整逐帧骨骼动画。
- 音效为 Web Audio 程序化提示音，尚未加入正式音乐与配音。
- 进度只保存在当前浏览器会话，刷新页面后重新开始。
- 公主在初版以结局叙事出现；下一版可补充独立角色立绘与救援过场。
