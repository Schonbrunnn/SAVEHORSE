# 宝马之路：立体路线与守卫更新

沿用 Phaser + Vite + GitHub Pages，不改变三大关卡、双主角和商人五选一系统。本轮优先解决“机关不影响路线、始终贴地向右走”的结构问题，而不是增加装饰平台。

## 实际路线

| 关卡 | 必经路线 | 分支与回接 |
| --- | --- | --- |
| 山门 | 两侧阶梯上行 → 盾卫长 → 攻击绞盘 → 山门开放 → 两批伏兵 → 峡谷落桥 → 洞窟 | 两组阶梯可选；开启绞盘后升降台直达中庭 |
| 洞窟 | 两批佣兵 → 交汇井下行、向左进入配重室 → 攻击配重机关 → 乘升降台返回 → 秦岭杀人兔 → 向右下井 → 击碎排水石壁 → 乘升降台前往木屋 | 交汇井可上行至旧矿廊，挑战裂岩监工获得两份额外补给；配重也接通后，井口落下捷径桥 |
| 基地 | 多批草莓熊 → 中枢 → 上层冷却电源与下层动力电源 → 双回路主闸 → 博士机甲室 | 两处电源可按任意顺序开启；下层由莓核巡卫守卫；每条回路都开启通回中枢的升降捷径 |

洞窟与基地现在有真正的地下通道，摄像机同时跟随横向和纵向移动。保留地面上的 C / D 竞技场、博士双层平台与木屋剧情。没有坠落死亡：落入地图底部空隙会回到最近安全落脚点，不扣血。

## 三个小 Boss

| 名称 | 地点 / 性质 | 招式与反击窗口 |
| --- | --- | --- |
| 盾卫长 | 山门绞盘楼，必打，150 HP | 盾击前摇 0.52 秒、重盾落砸前摇 0.85 秒；绕背或二段跳躲开后反击 |
| 裂岩监工 | 上层旧矿廊，可选，205 HP | 横扫前摇 0.68 秒、击倒重锤前摇 1 秒；不打也可走下层主路 |
| 莓核巡卫 | 基地下层动力室，必打，210 HP | 三线瞄准与扇形弹幕；空中攻击 10 秒，落地休息 4 秒；敌方弹丸仍共用最多 10 发限制 |

小 Boss 的初版放大小兵方案已被独立美术替换，详见 [独立美术与动作更新](2026-09-15-小Boss独立美术与动作.md)：每人 12 个独立姿态，盾卫长为铜面具方盾守卫，裂岩监工为持镐锤的工业矿工，莓核巡卫为悬浮反应炉机械。主角脸部没有改变。被打断时显示 Hurt；抗打断窗内受击仍闪白和播放音效。击败后留下各自无碰撞遗骸，掉落补给并清理自身残弹。

战败从对应守卫房间入口满血重试，保留已经接通的机关和已经清除的 Wave。大 Boss 仍从大 Boss 战前重试；切换大关卡时不带入上一关检查点。普通探索阶段死亡仍使用原有本关重试逻辑。

## 让机关具有必要性

- 主闸的实体封锁覆盖整个地图高度，不能从顶部或地下绕过；流程同时校验机关状态，避免越界直接触发 Boss / 出口。
- 所有战斗区、机关、落石和出口采用高度判断，不再只根据玩家横坐标触发。
- 地面不再全关连续铺满，井口、下层地板和峡谷都有实际碰撞结构。
- 可选矿廊的捷径桥必须在下层配重已接通后才落下，不会提前封死唯一必经井口。
- 小地图显示已探索房间、连线、玩家、机关和闸门状态；战斗期间收起，保留战斗 UI 的优先级。

## 参考与边界

参考的是“连通空间、分支探索、解锁回程”的组织方式，不复制《空洞骑士》的地图、美术、角色、音效或代码。来源：[Team Cherry 官方游戏介绍](https://www.teamcherry.com.au/games)、[Nintendo 对 Team Cherry 的开发者访谈](https://www.nintendo.com/au/news-and-articles/the-metamorphosis-of-hollow-knight-with-team-cherry-aussie-developer-interview/)。分层房间和回接路线是本项目据此作出的设计选择，并非逐项照搬原作机制。

当前仍是三段紧凑关卡，并非完整银河恶魔城大世界。本轮复用已有独立透明环境贴图，地面改为分段拼接避免长平台贴图被拉伸；背景暂为原场景上下扩展，没有声称完成全套新场景原画。

## 检查

`node scripts/verify-route-maps.mjs` 验证真实 Traversal 控制器中的全高封锁、双回路两种顺序、守卫触发与清场、捷径前置条件、机关恢复、隔层触发以及保守双跳 / 升降回接几何。`verify-combat-rules.mjs` 覆盖原有 C / D 战斗规则及守卫检查点。构建与这些回归检查不等同于真机触屏手感测试。
