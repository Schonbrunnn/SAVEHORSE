# 地图节奏与区域美术更新

## 第一关：先学会操作，再遇守卫

路线：松林驿道 → 可选旧驿站屋顶补给 → 普通伏兵 Wave1 / Wave2 → 钟楼脚下休整 → 后山钟楼盾卫长 → 绞盘 / 回程升降台 → 峡谷落桥 → 洞窟前庭。

地图从4600扩展到6200；首个小Boss的触发线放在3820（全图约62%），并要求两批普通伏兵已经清空。开场没有守卫，也没有要求先击败守卫才能开始教学的绞盘门。

钟楼通过三级石阶登上，击败盾卫长后开启绞盘；绞盘同时开启山门、峡谷桥与返回山道的升降台。钟楼上方保留可选屋顶补给。掉落继续回到安全落脚点，不设计坠落死亡。

## 第二关：明确三层结构

普通伏兵之后进入交汇井：上层为可选裂岩监工与补给，下层为必须接通的配重机关，回到地面后进入秦岭杀人兔竞技场。战后通过排水暗道返回木屋，仍然由玩家亲自走过去，不切图跳过道路。

配重机关到门闸有可视连接，启动后亮起。木屋回程升降台移至4710，为站在台边的玩家身体留下完整的上行间隙，避免顶住上层地板。

## 第三关：两条不同形象的回路

上层冷却室使用冷却泵与高位管线；下层动力室使用机械门框、动力装置与储罐。玩家仍可自行选择上下回路顺序，接通后线路与主闸响应，保留回到中枢的升降捷径。最终机甲战及双层战斗平台保持。

## 场景资产

内置imagegen各生成一套山地、矿井、基地资产，共3次，无复用其他游戏美术。每套2张背景、6件独立透明物件，共6张背景与18件新美术：可行走台面、结构柱、拱门、机关组件、地标、环境杂物。另从柱身确定性提取3条门闸结构纹理。

原画与实际提示词：`art-source/world-v3/`。实际原画尺寸1254×1254；保留原图，算法完成分离、透明杂点清理和留白，不伪称高分辨率重绘。运行时打包为三张1280×1280 WebP图集，预览PNG不预加载。

背景改为固定画幅的两层视差图，在上下房间间渐变，不再上下重复铺整张场景。可站立平台全部使用本区域台面图，并与原有碰撞坐标对齐；其他支柱、地标位于角色后方，是布景而不是隐藏碰撞体。机关线路是实际机关—门闸关系的功能提示，不新增操作按键。

## 流程防护与验证

普通伏兵区和Boss竞技场的远端增加实体封锁，清空对应战斗后解除；战斗仅在角色落到对应楼层后触发，避免从上层经过就开战或越过竞技场后被拉回。落石仅在附近触发，不因远处折返突然启动。

覆盖检查：关卡先后顺序、62%触发线、守卫复活点、真实上下楼层判定、两种回路顺序、必要机关、双跳距离、升降台全身间隙、Phaser实际图集解析、透明边界和资源体积。保留英雄面部、原有Boss招式、手机按键布局与技能CD；本轮没有真实iOS设备手感测试。
