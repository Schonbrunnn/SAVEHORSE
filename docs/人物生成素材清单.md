## 实际提示词

### A 四动作：主生成（built-in ImageGen，reference generation / identity-preserve）

```text
Use case: identity-preserve
Asset type: production-ready 2D horizontal character action sheet for a side-scrolling game
Input images: Image 1 is the identity and costume reference for Character A, “Captain Xiaoyu.”
Primary request: Generate one transparent-background horizontal action sheet containing exactly four clearly separated poses of the exact same Character A, in this left-to-right order: (1) idle ready stance, (2) running to the right, (3) shield bash toward the right, (4) throwing the shield toward the right with the shield visibly released from his hand.
Subject and identity lock: Strictly preserve the same recognizable adult Chinese male face from Image 1: same facial proportions, short tousled black hairstyle, silver thin-frame glasses, faint moustache and chin stubble, complexion and overall likeness. Strictly preserve the same red, navy-blue and silver armored superhero outfit, cape, boots, gloves, and the same large circular metallic red-blue-silver shield design and proportions. Do not redesign the character.
Style/medium: polished high-resolution 2D painted game character art with crisp silhouettes and clean cutout edges; semi-realistic heroic illustration matching the reference; NOT pixel art.
Composition/framing: landscape canvas; exactly four equal invisible cells in a single horizontal row; one action per cell; all figures face right in true side view; complete full body visible in every cell; same character scale, same baseline, and same overall height across all four cells; generous transparent spacing; no overlap between cells; nothing cropped.
Scene/backdrop: genuine transparent alpha background only, no floor, no shadow plate, no scenery, no colored backdrop.
Constraints: preserve face, hair, glasses, armor, cape and shield identity across all four poses; anatomically coherent limbs and hands; shield count and placement must match each action; no labels, no captions, no letters or readable words, no panel borders, no watermark, no extra characters, no extra limbs, no duplicate props.
Avoid: front-facing or three-quarter views; inconsistent face; missing glasses; costume drift; chibi; pixel art; opaque or checkerboard background; motion blur that obscures silhouette.
```

### A 四动作：纯绿底编辑（built-in ImageGen，precise background replacement）

```text
Use Image 1 as an exact 2D game asset edit target. Replace only every gray-and-white checkerboard background square with one perfectly uniform, solid chroma-key green field (#00FF00). Keep the four foreground character poses, faces, armor, capes, shields, action effects, spacing, canvas, edges, and colors unchanged. The background must be flat green with no checker pattern, gradient, texture, shadow, scenery, text, or watermark.
```
