# 写实场景组件 · v1

本轮使用内置 imagegen，逐件生成 6 张独立素材，不采用整张拼图裁切，不改人物脸部或角色动作素材。美术依据现有秦岭山道和草莓熊基地背景：真实风化材质、冷光环境、自然边缘，无卡通描边。

## 文件

- `art-source/props-v1/`：完整 PNG 原图与 `generation-prompts.json` 精确提示词记录，不随 Pages 游戏静态目录加载。
- `public/game/assets/props/`：独立透明 WebP 运行素材，`manifest.json` 记录尺寸与边缘处理。
- `scripts/build-prop-assets.mjs`：可重复的透明通道清理、空白裁切、2px 安全边距及压缩过程。没有重新绘制或生成像素内容。
- `game-src/EnvironmentArt.js`：共享加载清单。

| 素材 | 游戏用途 | 约束 |
| --- | --- | --- |
| bones-v1.webp | 小怪死亡后留下的干燥白骨堆 | 无血肉；无碰撞；置于脚下地面或平台，不跟随尸体悬空 |
| crate-v1.webp | 可击碎木箱 | 原 72×68 碰撞体不变；视觉约 74×70 |
| stone-platform-v1.webp | 山道及洞窟平台 | 图片上沿对齐原可站立面；宽度使用地图数据 |
| metal-platform-v1.webp | 基地平台 | 无栏杆遮挡；金属、铆钉与红色灯带 |
| cabin-v1.webp | 神秘商人木屋 | 两扇门；以进入与离开触发点的中点定位；剧情与选择逻辑不变 |
| boulder-v1.webp | 落石机关 | 保留原预警、落速和伤害逻辑 |

额外移除了覆盖在背景上的明亮地面横条与重复圆点。保留攻击提示、危险预警和回血心形等功能性反馈。

重建素材：`node scripts/build-prop-assets.mjs`。常规游戏构建直接使用已处理、已纳入项目的 WebP 文件，不重复调用图片生成服务。
